Team rules

Change the naming rules without code. Empty boxes keep the standard.

Consent endings (MKT, ANL, FUNC) and the item codes (CE, PV, DLV…) stay fixed – the whole convention and the skill depend on them.

My vendors

Vendors the tool does not know yet. Give the name to use and words that identify it in tag names, template names or the tag code (a script domain works well). Their tags, triggers and folders then follow the same rules as built-in vendors.

Fix list

Brand library

The names every brand shares. An item set up the same way as in a brand already in the library (same type, same events, same conditions) gets that brand's name, so all brands end up with the same names. Save each brand after you are happy with its names.

      Format: Vendor - Trigger type - Action - Consent. The vendor comes first when the trigger is used only by one vendor's tags. The action keeps the old name's own words ("OT Performance - Add to Wishlist" → Contentsquare - CE - Add to Wishlist - ANL); the event from the configuration is used only when the old name says nothing. A trigger shared by tags of several vendors is Trigger type - Action - Consent, with no vendor name anywhere (CE - purchase - MKT, PV - All Pages, not PV - All Pages - for GA4). The action is the event or page as written in the dataLayer. The consent ending (MKT, ANL, FUNC) always comes last, only when a condition really checks consent. No word is repeated: vendor words, the trigger type and repeated event names are dropped from the action. "OT", "OT Marketing" and "OT Performance" are never kept.
